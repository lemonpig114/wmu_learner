# 阶段 03:教务自动获取课表(统一身份认证)+ 界面改版

> 本记录由 WorkBuddy 生成(主开发工具)。日期:2026-10-30。

## 一、阶段目标与当时的做法

**目标**:① 界面美化并适配屏幕——周一到周日**同屏展示,不左右滑动**;② 尽量做到**零操作自动获取课表**(用户在「我的」里配置一次学号密码)。

### 1.1 自动获取的可行性实测(全部匿名抓取真实站点,未使用任何猜测)

| 事实 | 实测证据 |
|------|----------|
| 登录走**统一身份认证**(与用户说明一致) | `GET https://jwxt.wmu.edu.cn/sso/jziotlogin` → 302 → `https://authserver.wmu.edu.cn/authserver/login?service=http://jwxt.wmu.edu.cn/sso/jziotlogin` |
| 认证服务器为金智 authserver,表单 `POST /authserver/login?service=…` | 字段 `username`(学号) / `password` / `execution`(服务端下发) / `_eventId=submit` |
| **首次登录不需要验证码** | 验证码容器 `<div id="captchaParent" style="display: none;">` 默认隐藏(仅失败若干次后由服务端要求) |
| 密码**无前端加密**,HTTPS 明文提交 | 页面无任何 AES/RSA/salt 加密 JS;唯一外链 `init.js`(4.5KB)不含加密逻辑 |
| CAS 回跳为 **http** 协议,需定点放行 | `service=http://jwxt.wmu.edu.cn/sso/jziotlogin` → 因此加 `network_security_config` 仅对两个校园域名允许明文 |
| 裸 curl/HEAD 会被 WAF 拦(403) | 需带浏览器 UA;HEAD 直接 403,GET 正常 |

**结论**:零操作自动获取**可行**。

### 1.2 做法

1. `jwxt/JwxtClient`:按主机分别保管 Cookie(不把教务会话发给认证服务器)→ SSO 登录(账号+密码+execution)→ **会话校验**(教务首页可访问且不跳登录页)→ 取个人课表查询页 HTML → **从页面里发现**导出链接 → 逐个请求并按 `%PDF` 魔数校验 → 返回 PDF 字节。
2. `security/SecureStore`:账号密码用 **Android Keystore 生成的 AES-256/GCM 密钥**加密后存应用私有 SharedPreferences;不写日志、不上传、可一键清除。
3. 网络策略:`res/xml/network_security_config.xml` 默认仅 HTTPS,**仅** `jwxt.wmu.edu.cn`、`authserver.wmu.edu.cn` 允许明文(CAS 回跳所需)。
4. 「我的」页新增「教务账号(自动获取课表)」卡片:配置/修改/清除 + 学号打码显示;「课表」页顶部新增「自动获取」。
5. 自动获取流程复用第二阶段同一条链路:PDF → `WmuTimetableParser` → **预览校正** → 事务保存;失败时给明确原因并提供「诊断」按钮(记录每一步 HTTP 结果、发现的候选链接,学号打码)。
6. 界面改版:网格改为**权重布局**(7 天同屏、仅纵向滚动)、今日列高亮、课程卡片圆角与配色统一、周次选择器显示**日期区间**(如 第9周 · 10/27-11/2);主题补齐 `surfaceContainer` 系列颜色角色,修掉导航栏/FAB 退回 Material 默认紫色的问题。

### 4.2 修改与否决记录

- **采用用户提示修正方向**:原实现按教务本地登录表单(`login_slogin.html` + RSA 密码加密)设计;用户指出实际走统一身份认证 → 改为 **SSO(authserver)为主路径**,并按实测去掉不需要的加密实现。
- **否决「硬编码 PDF 导出地址」**:导出入口从**实际页面 HTML 中运行时发现**,发现不到时记录相关片段并如实报告,不猜接口。
- **否决「自动重试登录」**:页面实测 `dlsbsdsj=5`(失败锁定),只做单次尝试,避免把用户账号锁掉。
- **否决「密码/账号进入日志与诊断」**:诊断只输出流程与 HTTP 结果,学号一律打码(仅后 4 位)。
- **否决「全站放行明文流量」**:仅对两个校园域名开放 cleartext,其余仍强制 HTTPS。
- **修改「主题不完整」**:此前只覆盖部分颜色角色,导致导航栏/FAB 显示为 Material 默认紫色(真机截图发现)→ 补齐 surfaceContainer 系列。
