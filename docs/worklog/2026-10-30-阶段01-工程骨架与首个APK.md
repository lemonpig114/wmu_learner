## 一、阶段目标与当时的做法

**目标**:建立可编译、可安装的最小工程;实现「今天/课表/待办/我的」四页面与底部导航;本地新增与保存一条任务(Room 持久化,重启不丢);内置浏览器页面(WebView,为第三阶段教务登录做准备);初始化 Git 与 .gitignore;产出首个可安装 APK。

**做法**:

1. **Gradle Wrapper**:用本机缓存的 Gradle 9.4.1 发行版执行 `gradle wrapper --gradle-version 9.4.1`,生成 wrapper 三件套;遇 `include(":app")` 但目录不存在导致任务失败,创建目录后重试成功(17s)。
2. **版本目录**:`gradle/libs.versions.toml` 集中管理版本(AGP 9.4.1 / Kotlin 2.4.21 / KSP 2.3.12 / BOM 2026.09.00 / Room 2.8.5 / Nav 2.10.2 / activity-compose 1.13.0 / core-ktx 1.19.1 / icons-core 1.7.8)。
3. **工程结构**(包名 `com.wmu.keban`):
   - `data/`:Room 实体 `TaskItem`(标题/课程/备注/截止/完成/示例标记/来源/来源链接/最后同步时间/创建更新时间)、`Setting`(键值对,存学期起始日)、`AppDatabase`(v1,不启用破坏性迁移)、`KebanRepo`(仓库)、`Graph`(轻量服务定位)
   - `ui/`:四页面 + `KebanApp`(NavHost + NavigationBar)+ theme(浅/深色)
   - `ui/browser/BrowserScreen.kt`:WebView 页,安全边界见下
   - `util/Dates.kt`:截止时间/教学周计算,**缺失截止一律显示「未设置」,不猜测**
4. **示例数据策略**:首次启动且库为空时写入一条 `isSample=true` 的示例待办,UI 显示「示例」徽章,可删除;一旦用户产生真实数据即不再写入。真实数据与示例数据同表不同字段标记,明确区分。
5. **WebView 安全边界**(第三方网页与原生能力隔离):
   - 仅申请 `INTERNET` 权限
   - `allowFileAccess=false`、`allowContentAccess=false`(禁 file://、content://)
   - `shouldOverrideUrlLoading` 拦截一切非 http/https 协议(防 intent:// 跳转)
   - 不记录 Cookie/凭据/浏览历史,不开启远程调试;下载功能暂不启用(第三阶段按教务真实流程实现)
6. **Git**:`.gitignore` 排除构建产物、IDE 配置、`local.properties`、密钥类(`*.jks`/`*.keystore`)、日志、**全部 PDF**(`*.pdf`)与 `.analysis-local/`(个人课表分析数据)。
7. **本机配置说明**(不入 Git):`local.properties` 指向本机 SDK;`~/.gradle/gradle.properties` 写入本机代理(127.0.0.1:55880),因 Java 不读取 curl 的代理环境变量。
