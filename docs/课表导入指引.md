# 课表导入指引（v0.2.8）

> 本文由 WorkBuddy 生成。适用于温州医科大学「课伴」App 的课表导入。
> 文中不含任何账号、密码、Cookie 或课表内容。

---

## 一、推荐：一键获取（点一下就好）

**前置条件（只需做一次）**：在内置浏览器里登录一次学校统一身份认证。

**操作步骤**

1. 打开 App → 底部「我的」→「打开内置浏览器登录」
2. 在浏览器里输入学号 + 密码完成登录（需要验证码时按提示输入）
3. 登录后进入「学生课表查询」页，**确认能看到课表表格**（学年 / 学期 / 点「查询」）
4. 左上角返回，回到「课表」页 → 点右上角 **「一键获取」**

**然后应用会自动完成**：

```
① 打开教务课表页 → ② 点击页面「输出 PDF」→ ③ 捕获网站真实发出的请求
→ ④ 原样重放取回 PDF → ⑤ 自动跳回课表页并弹出「解析结果预览」
```

6. 在预览里核对条目：无法确定的信息会标红「待确认」（如"场地未排定""考核方式:未安排"），
   可逐条修正或删除；确认无误后点保存。

> 说明：为什么不能"完全零操作"？学校统一身份认证的登录需要图形验证码（按会话风控判定），
> 这一步必须由人完成。登录一次后会话会保留，之后取课表就不用再登录。

## 二、兜底：自己导出 PDF 再导入（一定可用）

**方式 A · 手机内**

1. 内置浏览器登录后，自己在页面上点 **「输出 PDF」**
2. 若手机弹出下载，应用会接住并提示"已获取课表 PDF"
3. 切到「课表」页，会自动弹出解析预览

**方式 B · 电脑导出（推荐在登录出问题时用）**

1. 电脑浏览器登录教务系统 → 学生课表查询 → 输出 PDF
2. 把 PDF 传到手机
3. App「课表」页 → 右上「导入」→ 选择该 PDF

> 这条路径**已用真实课表验证**：52 个上课时段 → 10 门课程，无丢失；单双周、不连续周次、
> 跨节、多时段均已核对。

## 三、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示"未找到「输出 PDF」按钮" | 还没登录或不在课表页。请先在本页登录并进入「学生课表查询」页（应用会自动弹出导入指引） |
| 提示"未检测到登录会话" | 会话过期（学校有有效期）。回内置浏览器重新登录一次 |
| 登录页白屏 | 已在 v0.2.4 修复（原因是登录表单所在的 iframe 在手机 WebView 里高度坍缩为 0） |
| 导出后没反应 | 回浏览器点「自检」，看"导出相关请求"是否出现 `POST .../xskbcx_cxXsShcPdf.html` |
| 想换学期 | 在课表页先选好学年的学期再点「输出 PDF」，导出的是当前查询条件的结果 |
| 重复导入同一份课表 | 应用按**解析后内容**判断是否重复（同一课表多次导出的文件哈希不同），不会产生重复课程；手动添加的课程会保留 |

## 四、失败时怎么反馈

点「自检」把弹窗内容截图给开发者即可。诊断信息已做隐私处理：

- 学号打码；不显示 Cookie 的值，只显示名称
- 地址统一去掉查询参数（避免把会话串写进去）
- 只显示页面结构、字段**名**，不显示字段值与课程内容

## 五、开发侧备注（供后续维护）

- 导出接口：`POST /jwglxt/kbcx/xskbcx_cxXsShcPdf.html`（由真机网络请求实测得到，非猜测）
- 取数方式：不硬编码参数，改为**在页面内挂钩**捕获网站自己发出的请求（表单提交 / XHR），
  再按原方法、原地址、原字段重放；这样网站改版时不需要改应用
- 登录链路：`jwxt.wmu.edu.cn/sso/jziotlogin` → `authserver.wmu.edu.cn/authserver/login`
- 会话保存在系统 WebView 的 Cookie 中（`JSESSIONID` 等），「我的」里可一键清除
