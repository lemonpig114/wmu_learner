# 课表导入指引（v0.4.0）

> 本文由 WorkBuddy 生成。适用于温州医科大学「课伴」App 的课表导入。
> 文中不含任何账号、密码、Cookie 或课表内容。

---

## 零、首次使用：三处一次设置（之后基本不用再管）

| 设置项 | 位置 | 说明 |
|---|---|---|
| 教务账号 | 我的 → 教务账号 | 填学号 + 统一身份认证密码。**打开「自动填入账号密码」** 后，登录页会自动帮你填好；再打开「自动提交登录」就能一次登录到底 |
| 节次时间表 | 我的 → 节次时间表 | 点「按此生成到文本框」，默认 **第 1 节 08:00 / 每节 45 分钟 / 课间 5 分钟**，三个数字都能改；生成后可逐节修正 |
| 学期周次 | 我的 → 学期设置 | 用「**按“现在是第几周”校准**」——填本周是第几周即可，应用自动反推第 1 周周一 |

设置完这三项后：**「今天」页会显示今天的课与上课时间；「课表」页一进去就自动定位到当前教学周**。

---

## 一、推荐：一键获取（点一下就好）

1. 「课表」页 → 点 **「一键获取」**
2. 应用自动：打开教务课表页 → （如已开自动登录则自动登录）→ 点击页面「输出 PDF」
   → 捕获网站真实请求 → 重放取回 PDF → **自动跳回课表页**并弹出「解析结果预览」
3. 在预览里核对/修正标红「待确认」的条目 → 确认保存

> 若某次登录被要求图形验证码，账号密码会自动填好，你只需输验证码再点登录（这是学校的风控，无法绕过）。

---

## 二、兜底：自己导出 PDF 再导入（一定可用）

**方式 A · 手机内**：内置浏览器里点「一键导出课表」→ 成功后切到「课表」页会自动弹预览。
**方式 B · 电脑导出**：电脑上导出课表 PDF → 传到手机 → 「课表」页右上「导入」→ 选该 PDF。

> 这条路径**已用真实课表验证**：52 个上课时段 → 10 门课程，无丢失；单双周、不连续周次、
> 跨节、多时段均已核对。

## 三、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示"未找到「输出 PDF」按钮" | 还没登录或不在课表页。请先登录并进入「学生课表查询」页（应用会自动弹出导入指引） |
| 提示"未检测到登录会话" | 会话过期（学校有有效期）。回内置浏览器重新登录一次 |
| 登录页白屏 | 已在 v0.2.4 修复（表单所在 iframe 在手机 WebView 里高度坍缩为 0）。还不行可在浏览器「更多」里试「简版登录页」 |
| 账号密码没自动填 | 我的 → 教务账号 里检查是否已配置、开关是否打开；自动提交在同一登录页只提交一次，失败不重试（学校规定连续失败 5 次锁号） |
| 课表页没定位到当前周 | 我的 → 学期设置 → 按「现在是第几周」校准 |
| 节次时间不显示 | 我的 → 节次时间表 里生成/填写；未填写的节次只显示节次、不显示时间（不会猜） |
| 重复导入同一份课表 | 按**解析后内容**判断重复，不会产生重复课程；手动添加的课程会保留 |

## 四、失败时怎么反馈

在浏览器「更多」→「自检与诊断」，把弹窗内容截图给开发者即可。诊断已做隐私处理：

- 学号打码；Cookie 只显示名称不显示值
- 地址统一去掉查询参数（避免会话串写入）
- 只显示页面结构、字段**名**，不显示字段值与课程内容

## 五、开发侧备注（供后续维护）

- 导出接口：`POST /jwglxt/kbcx/xskbcx_cxXsShcPdf.html`（真机网络请求实测，非猜测）
- 取数方式：不硬编码参数，改为**在页面内挂钩**捕获网站自己发出的请求（表单提交 / XHR），
  再按原方法、原地址、原字段重放；网站改版时应用无需改动
- 登录链路：`jwxt.wmu.edu.cn/sso/jziotlogin` → `authserver.wmu.edu.cn/authserver/login`
  - 登录表单在**同源 iframe** 内；自动填入按"第一个文本框 + 第一个密码框 + 所属表单"定位，不硬编码选择器
  - 自动提交有防锁保护：同一页面只提交一次，进程内最多 2 次
- 会话保存在系统 WebView Cookie（`JSESSIONID` 等），「我的」里可一键清除
- 节次时间存储：`settings.section_times`，格式 `1=08:00-08:45;2=08:55-09:40`
